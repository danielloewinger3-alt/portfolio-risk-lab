# Progress log

Agents append one entry per completed milestone (newest at the bottom). Format:

```
## M<n>: <title>  (YYYY-MM-DD HH:MM)
- Built: ...
- Verified: ... (commands run, test counts)
- Surprises / notes: ...
```
