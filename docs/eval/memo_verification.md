## Notes

- Rates over 4 portfolios are coarse; at temperature 0 each committed run is a single deterministic draw, so the sensitivity check samples extra drafts at a higher temperature to show how often the model can pass at all.
- A fallback is the safety design working, not a crash: the reader gets a template memo whose every figure is substituted from code and verified.
- Most violations are the model typing a figure it saw in the FACTS list (for example '1.08' instead of [[fact:sharpe]]). Small local models follow the placeholder rule less reliably than the API model the spec assumed (D12/O6 change, DEVIATIONS.md).
- A malformed_output violation (for example a draft that loops until the token limit and is cut off mid-JSON) stops the scan, so that draft's violation count is 1 even though its prose may also contain stray numbers.
- Prompt iterations tried before these runs (all on Tech heavy, all still failing): showing values as 'never type it'; listing the matching placeholder for each stray number in the retry; not echoing the rejected draft in the retry. The verifier and allowlist were not loosened to make drafts pass.
