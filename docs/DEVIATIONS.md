# Deviations

Log every departure from a locked decision (`00-decisions.md`) or interface contract (`03-architecture.md`).

| Date | Milestone | Deviation | Reason | Impact on other modules |
|---|---|---|---|---|
| 2026-10-30 | M1 | `Portfolio` gains an optional `name` field (after `rf_annual`), defaults `benchmark="SPY"`, `start` = today minus 10y, `end` = today, `rf_annual=0.03`. Equality and hash come from `Portfolio.key` (frozen, `eq=False` dataclass), since a `pd.Series` field breaks dataclass `__eq__`. Added `Portfolio.from_weights(mapping, *, allowed_tickers=None, **kw)`, and `from_table` also takes `allowed_tickers` | Sample-portfolio labels; usable as a cache key; offline mode must reject non-universe tickers | Contract names and semantics are unchanged. UI adapters can hash `Portfolio` directly |
| 2026-10-30 | M1 | Additions beyond the contract: `risklab.portfolio.load_portfolio_data(p, *, offline=None, min_obs=252) -> PortfolioData(prices, asset_returns, portfolio_returns, benchmark_returns, history, sources)` and `check_history()`; in `data/prices.py`, `align_returns`, `risk_free_from_irx`, `clean_prices`, `find_gaps`, `flag_return_outliers`, `fetch_live`, `load_bundle`, `bundle_manifest`, `bundle_snapshot_date` | One tested path from portfolio to aligned returns for every downstream module | Downstream agents should use `load_portfolio_data` instead of reimplementing alignment |
| 2026-10-30 | M1 | `portfolio_returns(asset_returns, weights)` uses weights **as given** (no renormalization) and inner-joins only assets with **non-zero** weight. `load_prices` records the per-ticker source in `DataFrame.attrs["sources"]` | Stress tests renormalize over covered assets themselves; a zero-weight asset should not truncate history | Stress agent: pass already-renormalized weights |
| 2026-10-30 | M1 | `RiskReport.add_fact(name, value, display, unit, *, source_fn="", overwrite=False)`: `display=None` auto-formats by unit; `unit` is one of `fraction, ratio, days, count, date, text, bool`; names must match `^[a-z][a-z0-9_]*$` (canonical names in the `FactName` StrEnum); non-finite floats are rejected (store `None` instead, which displays as `n/a`); `allowed_literals` + `allow_literal()` support the verifier. `build_report()` is not defined yet (M8, LLM agent) | Typed fact names plus the placeholder grammar | LLM agent adds `build_report` and new `FactName` members |
| 2026-10-30 | M1 | Shared helpers added outside the contract: `risklab.errors` (`RiskLabError`, `InsufficientDataError`, `DataUnavailableError`, `PortfolioValidationError`, `LLMUnavailableError`), `risklab.formatting` (`fmt_pct`, `fmt_ratio`, `fmt_number`, `fmt_days`, `fmt_date`), and `risklab.DISCLAIMER` | One source of truth for errors, display format, and the disclaimer | Use these; do not redefine them |
